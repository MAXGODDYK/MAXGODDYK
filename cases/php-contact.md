# PCMetrics · навчальна форма на PHP

Для навчального сайту про компоненти комп'ютера зробив контактну форму з обробкою на сервері. Перевіряю обов'язкові поля та формат email, екраную HTML під час виведення і викликаю функцію PHP mail() після перевірки.

Цей проєкт доповнив навчальний модуль з Apache, PHP та MySQL у коледжі. Моя практика PHP охоплює невелику форму та базову серверну обробку. Тут розміщено опис локального проєкту.

# Local LLM Desktop Chat

Створив Windows-застосунок для спілкування з локальними мовними моделями. У ньому можна обрати модель, почати розмову, бачити відповідь у міру генерації та зупинити запит. Історія розмов зберігається у SQLite.

**Інтерфейс.** Побудував клієнт на C#, .NET 9, WPF і XAML. Прив'язки даних пов'язують вікно з ViewModel, а зміни стану відображаються через INotifyPropertyChanged. Для дій користувача застосував асинхронні команди.

**Зв'язок із моделлю.** WPF-клієнт надсилає запити до локального Python/FastAPI через HttpClient. CancellationToken дозволяє скасувати активну генерацію. Логіку запитів і моделі даних відокремив від відображення.

На цій сторінці подано опис особистого локального проєкту. Публічний приклад іншої роботи на C# — навчальний довідник контактів. [Код довідника](https://github.com/MAXGODDYK/HomeWorks/tree/main/TelefonBookTest)

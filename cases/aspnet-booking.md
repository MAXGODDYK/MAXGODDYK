# Платформа запису на послуги

Для приватного проєктного замовлення створив вебзастосунок, де клієнт може зареєструватися, обрати послугу й оформити запис. Власниця керує заявками, послугами та цінами через Telegram.

**Backend.** Написав маршрути ASP.NET Core Minimal API для облікових записів, кабінету клієнта та бронювання. Додав підтвердження електронної пошти й відновлення доступу. Для даних використав SQLite, параметризовані запити й транзакції.

**Frontend.** На HTML, CSS та JavaScript створив форми реєстрації та запису, сторінки каталогу й особистий кабінет. Під'єднав їх до серверної логіки, щоб клієнт міг пройти шлях від вибору послуги до створення бронювання.

**Інтеграція.** Сайт і Telegram-бот читають один каталог зі спільної бази. Зміна ціни в адміністративному інтерфейсі бота оновлює дані, які відображає сайт.

Тут опубліковано опис мого внеску. Код замовлення зберігається у приватному репозиторії.

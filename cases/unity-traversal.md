# Рух персонажа у Unity для Windows

У тестовому завданні я працював із готовою сценою та контролером персонажа. Додав підйом і спуск драбиною та проходження крізь вікно в обох напрямках. Обидві дії запускаються, коли гравець підходить до перешкоди.

Для драбини узгодив рух персонажа з наданою анімацією, щоб руки й ноги торкалися щаблів. Для вікна синхронізував переміщення з тривалістю анімації. Якщо місце приземлення зайняте, дія не запускається. Після завершення або скасування гравець знову керує персонажем із клавіатури.

Зібрав проєкт у Unity 2023.2 для Windows x64. У запущеній збірці пройшла 51 автоматизована перевірка. Серед перевірених сценаріїв — прохід через вікно в обидва боки, заблоковане приземлення та повернення керування після скасування.

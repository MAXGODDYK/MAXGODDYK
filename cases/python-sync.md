# MAX · локальний каталог із синхронізацією

Створив Windows-застосунок на Python і Tkinter для обліку інгредієнтів, рецептів і розрахунку вартості партії. Дані зберігаються локально у SQLite, а для обміну зі спільною таблицею передбачена синхронізація через Google Sheets API.

Коли зовнішня таблиця недоступна, застосунок може записувати зміни в локальну чергу. Під час наступної синхронізації обробляє чергу та застосовує правило розв'язання конфліктів. Цю логіку перевіряв у тестах із підставним клієнтом Google Sheets.

Тут опубліковано опис проєкту. Відкритий приклад окремої Python-інтеграції — типізований інструмент для запиту офіційного курсу НБУ. [Код інтеграції з НБУ](https://github.com/MAXGODDYK/rag-homework/tree/HW_5/HW_5)
